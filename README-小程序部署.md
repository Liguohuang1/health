# 痴呆风险预测小程序部署指南

## 方案一：Web-view 方案（推荐）

### 优点
- ✅ 开发速度快，几乎无需重写代码
- ✅ 保持原有功能完整性
- ✅ 维护成本低
- ✅ 可以快速演示

### 部署步骤

#### 1. 部署HTML项目到服务器
将你的HTML项目部署到一个可访问的HTTPS域名，比如：
- GitHub Pages (免费)
- Vercel (免费) 
- Netlify (免费)
- 阿里云/腾讯云服务器

#### 2. 配置域名白名单
在微信小程序后台配置业务域名白名单：
1. 登录微信公众平台小程序后台
2. 进入「开发」->「开发管理」->「开发设置」
3. 在「业务域名」中添加你的域名

#### 3. 修改小程序配置
在 `miniprogram/app.js` 中修改 `serverUrl` 为你的实际域名：
```javascript
globalData: {
  serverUrl: 'https://your-actual-domain.com'
}
```

#### 4. 测试和发布
1. 使用微信开发者工具导入小程序项目
2. 在开发者工具中测试web-view功能
3. 上传代码并提交审核

### 注意事项
- ⚠️ 必须使用HTTPS域名
- ⚠️ 域名需要在微信小程序后台配置白名单
- ⚠️ 个人小程序不支持web-view，需要企业小程序
- ⚠️ web-view中的页面无法调用小程序API

## 方案二：原生重写（长期方案）

如果需要更深度的小程序集成，可以考虑将HTML项目重写为小程序原生代码：

### 优点
- ✅ 完全的小程序体验
- ✅ 可以使用小程序所有API
- ✅ 性能更好
- ✅ 支持个人小程序

### 缺点
- ❌ 开发周期长
- ❌ 需要重写所有页面
- ❌ 维护成本高

## 推荐部署流程

### 快速演示（推荐）
1. 使用 GitHub Pages 部署HTML项目
2. 使用web-view方案的小程序代码
3. 申请企业小程序账号
4. 配置域名白名单并发布

### 演示用免费部署方案
1. **GitHub Pages**:
   - 将代码推送到GitHub仓库
   - 在仓库设置中启用GitHub Pages
   - 域名格式：`https://username.github.io/repository-name`

2. **Vercel**:
   - 连接GitHub仓库到Vercel
   - 自动部署，提供免费HTTPS域名
   - 速度快，国内访问良好

3. **Netlify**:
   - 拖拽文件夹即可部署
   - 提供免费HTTPS域名
   - 支持表单处理等功能

选择任一方案部署后，更新小程序中的域名配置即可快速实现演示效果。
